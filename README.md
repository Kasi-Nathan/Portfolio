## TL;DR

Fork this repo to create your own portfolio. Please credit the original creator by linking back to [Kasi-Nathan](https://github.com/Kasi-Nathan).

## Built With

- React.js
- Node.js
- Express.js
- CSS3
- Vercel

## Features

**📖 Multi-Page Layout**

**🎨 Customizable and Minimal Design**

**📱 Fully Responsive**

## Installation

1. Clone the repository: `git clone https://github.com/Kasi-Nathan/Portfolio.git`
2. Install dependencies: `npm install`
3. Run the project: `npm start`
4. Open [http://localhost:3000](http://localhost:3000) to view your portfolio.

## Usage

Modify the `/src/components/` folder to update your information.
